什么是水平先验（Horizontal Prior）？

水平先验指这样一种现象：自然采集的真实图像绝大多数是接近水平拍摄的，绝对滚转角（roll angle）呈长尾分布。在这类数据上训练的单目深度估计（Monocular Depth Estimation, MDE）模型，对发生滚转的图像的深度误差显著大于对应的水平图像。以 Depth Anything V2 为例，测试图像从水平变为最大 90° 滚转时，AbsRel 从 0.096 升至 0.127，变差 32%（论文 Table 2 与附录 E）。

什么是 ID-Constraint？

不变深度约束（Invariant Depth Constraint, ID-Constraint）是一种只在训练阶段使用的监督策略：用六个旋转不变的辅助任务与深度损失联合微调深度主干网络，其中四个是区域级任务（光影、遮挡、大小、纹理梯度），两个是像素级任务（local peak、local slope）。训练结束后辅助预测头被丢弃，推理结构保持不变。在基准的三种滚转设置下它都取得最优结果，例如最大 90° 滚转时 AbsRel 为 0.106、δ1 为 0.913（Table 2）。

摘要

摘要（中文翻译）

以下为论文英文摘要的中文翻译，仅供参考，请以 arXiv 上的英文原文为准。

尽管单目深度估计近年来进展显著，最先进的深度基础模型仍然存在鲁棒性问题。尤其是，即使轻微的相机滚转也会导致深度估计明显退化。我们将这一问题归因于一个此前被忽视的现象，称为水平先验（Horizontal Prior），它是长尾分布偏差的一种表现：由于人类的视觉偏好和摄影习惯，大多数训练图像都是以近似水平的朝向拍摄的。再平衡数据增强和水平校正等直观的补救方法能带来部分改善，但无法彻底解决问题。本文提出不变深度约束（Invariant Depth Constraint, ID-Constraint），这是一种训练阶段的监督策略，通过一系列几何与空间推理任务对深度主干网络进行微调和联合正则化，从而提升对滚转的鲁棒性。这些辅助目标促使主干网络学习对旋转稳定、与深度相关的表征；辅助预测头在训练后被丢弃，原有的推理结构保持不变。在五个基准数据集、四种滚转设置上的大量实验证明了所提方法的有效性。

方法

两种直观方案，以及对特征的约束

  • 基线（Baseline）：沿用 Distill Any Depth 的蒸馏流程，以 Depth Anything V2（ViT-Large）为教师模型，在 200,000 张无标注 SA-1B 图像上训练；学生模型使用相同的 DINOv2 编码器（取第 4、11、17、23 层特征）和 DPT 解码头。
  • 再平衡增强（Re-balanced Augmentation）：训练时对每张图像在 [−90°, 90°] 内均匀采样角度并旋转，同时随机中心裁剪保留 40% 到 100% 的原图尺寸，以避免模型利用填充边界的捷径；保留 10% 的样本不做增强。
  • 水平校正（Horizon Leveling）：用一个 ViT-Small 滚转角预测模型输出二维向量 (cos θ, sin θ)，再把图像按预测角度转正。该模型采用带数据去噪的两阶段训练；即便如此，最好的模型平均误差仍有 25.90°（Table 1）。
  • ID-Constraint：在随机旋转的输入上，用 ID Heads 和 ID Losses 与深度损失联合优化 ViT 编码器，ID 损失以权重 1.0 直接加到总损失上。区域级任务选自 DepthCues 基准中标签不随旋转改变的四个任务（BCE 损失）；像素级任务 local peak（5×5 邻域平均有效深度减去该像素深度）和 local slope（四个方向上深度梯度绝对值的平均）由教师深度图计算得到（L1 损失），共用一个隐藏维度为 128 的 DPT 头。推理时丢弃所有 ID Heads。

问答

常见问题

单目深度估计中的水平先验（Horizontal Prior）是什么？

水平先验指自然采集的真实图像绝大多数以近似水平的朝向拍摄，导致绝对滚转角呈长尾分布；因此滚转角 θ 大于 0° 的图像的深度估计误差显著大于对应的水平图像。论文将其视为单目深度估计中一种新的长尾偏差来源，并给出三方面证据：两万张 SA-1B 图像的滚转角分布与平均深度图、多个 MDE 模型随滚转增大而退化、以及细粒度滚转角分析中模型表现与滚转角分布的相关性。

相机滚转时，Depth Anything V2 等深度模型会退化多少？

在五个基准数据集上平均，Depth Anything V2 从 Horizontal 到 Tipping [0°, 90°] 设置，AbsRel 从 0.096 升至 0.127（变差 32%），δ1 从 0.922 降至 0.883（下降 3.9 个点）。对论文图 1(a) 中滚转 45° 的单张图像，AbsRel 变差 45.7%（0.138 到 0.201），δ1 下降 8.7 个点（0.869 到 0.782）。Marigold 的 AbsRel 从 0.130 升至 0.200，GenPercept 从 0.130 升至 0.185，Distill Any Depth 从 0.099 升至 0.131（Table 2 与附录 E）。

为什么只做旋转增强或只做水平校正还不够？

再平衡增强把 Tipping 设置的 AbsRel 从 0.135 降到 0.119，但在水平图像上略差于基线（0.104 对 0.100），论文认为这是因为 DINOv2 预训练时没有这类增强，会扩大预训练与微调数据之间的域差异。水平校正依赖滚转角估计，而仅凭单张图像估计滚转角并不准确：论文中最好的预测模型平均误差为 25.90°（Table 1），改用 PerspectiveFields 后为 18.7°（附录 E）。仅用水平校正在 Tipping 设置下 AbsRel 为 0.112，ID-Constraint 为 0.106（Table 2）。

ID-Constraint 会让推理变慢或模型变大吗？

不会。ID-Constraint 不增加任何推理参数，因为辅助的 ID Heads 只在训练阶段使用，训练后即被丢弃。论文报告的配置中唯一的额外推理开销来自水平校正：一个约 21M 参数的 ViT-S 滚转角预测器，在单张 A100、batch size 为 1 时增加 15.4 ms 延迟（附录 E）。

ID-Constraint 会降低普通水平图像上的精度吗？

在 Horizontal 设置下，ID-Constraint 的 AbsRel 为 0.099、δ1 为 0.920，相同条件下训练的复现基线为 0.100 和 0.920（Table 2）。Depth Anything V2 在该设置下略好（0.096 和 0.922），论文将其归因于复现基线本身较弱，因为 DAv2 的训练代码并未公开。

模型权重和训练代码开源了吗？

没有。由于本工作所在公司的保密规定，且维护该仓库的作者已从该公司离职，所有训练好的模型权重以及大部分代码（包括全部训练代码）都无法公开。公开仓库包含五个数据集、四种滚转设置的评测代码、推理所需的模型结构定义、paired bootstrap 置信区间脚本以及 SA-1B 数据列表脚本；用公开的 Depth Anything V2 和 Distill Any Depth 权重即可运行对应评测。

代码与开源说明

仓库里有什么、没有什么

这项工作的动机来自一个真实的商业应用（手机拍摄的室内场景重建，论文图 2），公司的保密规定适用于相关代码和模型。维护该仓库的作者已从该公司离职，无法再访问未公开的部分。

已公开

  • test.py：在 DIODE、ScanNet、ETH3D、KITTI、NYUv2 上按四种滚转设置评测 DAv2 结构的权重；可直接用公开的 Depth Anything V2、Distill Any Depth 权重运行。
  • test_hl.py：带水平校正的同一评测流程。
  • datasets/：带旋转的评测 dataloader、样本列表、SA-1B 下载与列表脚本。
  • models/：深度模型、滚转角预测模型、区域级 ID heads 的推理结构定义。
  • paired_bootstrap.py：paired stratified bootstrap 置信区间。
  • _eval_others/：移植到 GenPercept、Marigold 中的滚转评测代码，以及 PromptDA、MoGe 的可视化脚本。

未公开

  • 全部训练好的权重：复现基线、再平衡增强模型、ID-Constraint 模型、滚转角预测模型。
  • 全部训练代码：蒸馏训练、ID 损失、local peak 与 local slope 目标的生成、DepthCues 训练 dataloader、滚转角预测模型的两阶段训练。

scripts/ 中评测这些权重的脚本作为评测流程的记录予以保留。
